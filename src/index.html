10차시 수업 흐름

5차시 · 검사 방침 비교

  1. 준비된 모델과 같은 검증 자료를 확인합니다.
  2. A/B 방침의 검사·보류 건수를 비교합니다.
  3. 검사 결과와 맞지 않은 예측을 찾습니다.
  4. 추가 검사 부담과 놓칠 수 있는 사례를 근거로 선택합니다.

품질 규격 480~520 nm는 고정입니다. 검사 방침을 바꿔도 실제 부적합이 합격으로 바뀌지 않습니다.

9차시 · 안전한 대응

  1. A 정상과 C 비상정지를 공통 시험합니다.
  2. ACK 후에도 정지 상태인지 확인합니다.
  3. 원인 해소 → RESET → 운전 허가 → 별도 시작을 구분합니다.
  4. B 또는 D 시험 결과를 다른 조와 공유합니다.

빨간 표시는 안전 정지, 노란 표시는 추가 검사·보류·입력 확인입니다. 색과 함께 상태 이름을 읽으세요.
